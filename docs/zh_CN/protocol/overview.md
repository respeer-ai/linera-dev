# 概述

Linera是一种去中心化协议，专为需要保障海量活跃用户性能的Web3应用而优化。

[Linera协议](https://linera.io/whitepaper)的核心设计理念是：在单一验证节点集群中运行多条并行链（称为**微链**），使链间能够轻松共享应用、数据及流动性。

## 工作机制

Linera协议中，每个用户钱包都对应一条专属链（称为**用户链**），可随时提议区块。这类单用户链的设计用途包括：
作为个人区块链空间存储资产，
接收外部资产转账，
与Linera生态应用发起交互。

Linera用户可直接向其专属链提议区块。关键机制在于：Linera验证节点集群将以完全一致的方式，对所有链上的区块进行验证和最终确认。

> 除用户链外，Linera协议还支持两类微链：**多用户链**与**公共链**。
> 共链由验证节点运营，通常为特定应用专用。
> 用户链由多个用户共享，主要用于原子交换、拍卖、链上游戏等临时性交互场景。
## 主要特性

**基础设施**

- 大多数区块（含执行证明）的最终确认时间＜0.5秒。

- 通过单笔交易即可从现有链创建新微链。

- 微链数量无理论上限，因此每秒交易处理量（TPS）可无限扩展。

- 兼容EVM签名机制的桥接友好型区块头。

**链上应用**

- 丰富的编程模型支持应用通过异步消息传递，共享不可变数据，事件流处理（*）跨链分发计算。

- 每条微链内部实现完全同步可组合性。

- 支持两类特殊操作：长耗时交易（执行时间可达数秒级）和直接预言机查询（访问外部Web服务及数据存储层）。

**Web客户端与钱包基础设施**

- 验证节点向Web客户端的实时推送通知。

- 针对选定微链的区块同步与虚拟机执行，实现用户交易的即时预确认。

- 使用熟悉的Web2框架实现无需信任的响应式编程。

- 使用Rust编程的链上应用（运行于WebAssembly），或Solidity语言在EVM上的实现(*)。

_(*)标记的功能计划于2025年第二季度推出。_

## Linera与传统多链协议有何不同？

Linera是首个专为并行运行近乎无限数量链而设计的区块链，其中包括每个用户钱包对应一个专用**用户链**。

在传统多链协议中，每个链通常需要独立验证节点集群运行完整区块链协议。创建新链或跨链通信成本高昂，因此链的总数通常受到限制。

相比之下， **Linera专为实现按需运行任意数量微链而设计**:

- 用户仅在需要时于自身链上创建区块；

- 创建微链无需引入验证节点；

- 所有链均具备同等安全等级；

- 微链通过验证节点内部网络实现高效通信；

- 验证节点内部采用分片架构（类似常规Web服务），并可弹性调整其容量，通过动态增减内部工作节点实现；

- 用户可在其微链中运行重型交易而不影响其他用户。
