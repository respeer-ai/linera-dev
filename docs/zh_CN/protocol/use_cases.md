# 为何要基于Linera进行构建？

## 高并发实时交互

在Linera，我们坚信Web3应用应能按需承载海量**活跃用户**，同时维持用户体验与安全标准不妥协。

需要处理大量同时用户（或设备）发起时效性交易的应用场景包括：

- 实时支付与微奖励，

- 实时拍卖系统，

- 链上游戏，

- 去中心化物理基础设施（DePIN），

- 社交数据流，

- 适用于软件、数据管道及AI训练的版本控制系统。

## 实时连接与便捷链下集成

Linera**用户链**的独特架构通过以下方式实现与外部系统的多维通信：

- Linera区块可即时生成适配低延迟桥接的执行验证证明。

- 交易可查询外部网络服务，例如AI推理系统或其他区块链的RPC提供商。

- 交易可持续数秒，使得应用程序能够轻松从外部存储下载数据或在链上执行高成本验证函数（例如ZK验证）。
